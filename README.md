## Ответы на вопросы

### 1. Чем `int.TryParse()` безопаснее `int.Parse()`?

`int.TryParse()` не завершает программу с ошибкой, если пользователь ввёл неправильное значение.
`int.Parse()` может вызвать ошибку. Поэтому `TryParse()` удобно использовать для пользовательского ввода.

### 2. Когда `switch` удобнее, чем `if/else if`?

`switch` удобнее, когда нужно сравнить одну переменную с несколькими конкретными значениями.

Например, можно определить день недели по его номеру.

### 3. Что будет, если убрать `break`?

В обычном `switch` выполнение может перейти к следующей ветке. Поэтому `break` нужен для завершения текущего `case`.

### 4. Чем отличается `=` от `==`?

`=` используется для присваивания значения.

`==` используется для сравнения двух значений.

Например:

```csharp
int number = 5;

if (number == 5)
{
    Console.WriteLine("Число равно 5");
}
```

### 5. Можно ли использовать тернарный оператор внутри другого?

Да, можно. Например:

```csharp
string result = score > 50
    ? score > 90 ? "Отлично" : "Хорошо"
    : "Плохо";
```

Но такой код сложнее читать, поэтому лучше не использовать много тернарных операторов друг внутри друга.
